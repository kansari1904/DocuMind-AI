# 📚 DocuMind AI

> An AI-powered full-stack web application that transforms PDF documents into interactive learning experiences using **Google Gemini LLM**.

DocuMind AI allows users to upload PDF documents and interact with their content using AI. After uploading a PDF, users can generate **summaries, flashcards, quizzes**, and **chat with an AI assistant about any concept inside the document**.

The application is designed to make studying, understanding, and revising PDF-based content faster and more interactive.

## ✨ Features

### 🔐 User Authentication

- User registration and login
- Secure authentication
- User-specific documents and data
- Protected application routes

### 📄 PDF Upload

- Upload PDF documents up to **10 MB**
- PDF text extraction using **Google Gemini**
- Process and analyze document content
- User-friendly document management

### 🤖 AI-Powered PDF Analysis

Once a PDF is uploaded, DocuMind AI uses the **Gemini LLM API** to understand the document and provide multiple AI-powered features.

### 📝 PDF Summary

Generate a concise summary of the uploaded document to quickly understand the important concepts and key information.

### 🧠 Flashcard Generation

Automatically generate study flashcards from the PDF.

```text
Question:
What is Machine Learning?

Answer:
Machine Learning is a branch of AI that enables systems
